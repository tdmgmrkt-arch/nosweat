## Top 5 SXO Improvements (Priority Order)

**1. Reposition the solar blog post — CRITICAL**
Retarget /blog/how-to-buy-the-right-solar-panels/ from a national buying guide keyword to "solar installation Moreno Valley CA" or "solar panels Inland Empire" where local relevance beats domain authority. Create a dedicated /service/solar/ page with solar contractor credentials, service details, and a local CTA. The current keyword target is unwinnable for a local HVAC company.

**2. Create city+service pages for AC repair — HIGH**
Build dedicated pages at slugs like /service-areas/moreno-valley/ac-repair/ and /service-areas/riverside/ac-repair/ for the top 5–6 cities. These are the pages Google rewards for "[city] ac repair" queries. The current /service/ac-repair/ page has no geographic anchor and is being outranked by city-specific pages from competitors.

**3. Expand the AC signs blog to 9–10 signs with FAQ schema — MEDIUM**
Increase /blog/signs-that-your-ac-needs-repair/ from 5 signs (~1,200 words) to 9–10 signs (~2,000 words). Add FAQPage schema to the existing FAQ-style content. Add an inline mid-content CTA after sign #3. Refresh the publish date. These changes directly target the featured snippet Google is serving for this query.

**4. Add FAQ schema to the Moreno Valley city page — MEDIUM**
The FAQ section on /service-areas/moreno-valley/ already contains 6 solid questions. Adding FAQPage schema takes 30 minutes of dev time and can trigger a Google rich result (expandable FAQ in SERP) that increases click-through rate without any content changes needed.

**5. Reduce contact form friction + add ContactPage schema — MEDIUM**
Split /contact-us/ into two tracks: a prominent click-to-call path for emergency visitors and a simplified 4-field form for scheduled service. Add ContactPage + LocalBusiness with openingHoursSpecification schema. Add a Google Map embed. These changes improve conversion for the site's highest-intent visitors and close a schema gap flagged across multiple pages.
